10 · 20 · 30초

먼저 장면을 보고,
그다음 영상을 결정하세요.

GPT가 프롬프트와 화면 움직임을 설계하고 장면 이미지를 만듭니다. 최종 승인을 누르면 로컬 FFmpeg가 이미지를 움직이는 MP4로 합칩니다.

준비 상태를 확인하는 중입니다.

01

장면 입력

원하는 장면을 적고, 기준 이미지가 있다면 첨부하세요.

PNG·JPEG·WebP, 최대 5MB. 이미지는 프롬프트 해석과 각 예시 이미지의 기준으로 사용됩니다.

프롬프트 보강 버튼은 OpenAI API를 호출하며 토큰 사용료가 발생할 수 있습니다. 키는 서버의 OPENAI_API_KEY에서 읽고 화면에 표시하지 않습니다.

02

구간별 스토리보드

보강한 내용과 10초마다 만들 장면을 확인하세요.

보강된 전체 프롬프트

첨부 기준 이미지

예시 이미지는 최종 영상의 9:16 기본 구도로 잘라 보여줍니다. 카메라 이동·확대 중에는 가장자리가 더 잘릴 수 있습니다.

OpenAI 이미지 출력 추정액입니다. 입력 텍스트·첨부 이미지 비용은 별도이며 실제 청구액은 달라질 수 있습니다.

프롬프트와 9:16 예시 구도를 확인한 뒤 선택하세요.

최종 단계는 승인한 이미지를 로컬에서 합칩니다. 카메라 이동 중 가장자리가 더 잘릴 수 있습니다. 추가 영상 API 요금은 없으며 피사체의 연속 동작을 생성하지 않습니다.
03

완성한 영상

확인한 장면으로만 제작한 MP4입니다.

MP4 다운로드

기존 작업은 로컬 workspace/storyboards/에 저장되며 Git에 포함되지 않습니다. 기준 이미지와 프롬프트는 명시한 OpenAI 요청에 전송됩니다.
