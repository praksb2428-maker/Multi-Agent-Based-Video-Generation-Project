# 테스트 계획 초안

검사의 기준은 [제안서](../Video_Production_Project.md)의 §3.1~3.3과 §4.1, 현재 단계는 [프로젝트 브리프](project-brief.md), 작업 중 실패 처리 한도는 [workflow](workflow.md)에 둔다. 이 문서는 **무엇을 어떻게 확인할지**만 관리한다. 전체 영상 제작 검사는 아직 실행 가능한 단계가 아니다.

## 현재 오프라인 범위

| 대상 | 전략 | 현재 상태 |
| --- | --- | --- |
| 입력 조건 | 합성 JSON으로 필수 항목·자료형·길이·비율·금지어 경계를 검사 | `tests/test_shorts.py`에 일부 구현됨 |
| 기획 JSON 계약 | 장면 순서·필수 필드·장면 길이 합계 ±10%·스키마 버전을 검사 | `tests/test_shorts.py`에 일부 구현됨 |
| 기획 승인 | 내용 해시, 승인 뒤 변경 시 무효화, 중복 승인을 검사 | `tests/test_shorts.py`에 일부 구현됨 |
| CLI 파일 처리 | 합성 입력으로 초안·승인 JSON의 생성과 파싱을 확인 | `tests/test_shorts.py`에 CLI 테스트가 있음 |

현재 관련 테스트 명령은 PowerShell의 저장소 루트에서 `.\.venv\Scripts\python.exe -m unittest discover -s tests -v`이다. 앞 단계에서 Python 3.12.7로 5개가 통과했지만, **이번 문서 변경 이후의 P4 검증 결과를 뜻하지 않는다.** 실행·출력 절차의 최종 확인도 P4에서 수행한다.

## 후속 구현 시 검사할 범위

| 대상 | 전략 | 상태 |
| --- | --- | --- |
| 에이전트 간 전달·재개 | 버전 있는 JSON 계약, 누락 필드, 승인 상태 복원, 수정된 내용의 재승인 검사 | 미구성 |
| 비용·제작 승인 | 견적·최대 예산·승인 전 제작 중단·유료 재생성 추가 승인 검사. 외부 호출은 가짜 도구로 우선 검증 | 미구성 |
| 외부 API 경계 | 제공자·모델 확정 후 입력/출력·실패·재시도·비용 기록을 제한된 계약 검사로 확인. 실제 유료 호출은 별도 결정 | 미구성 |
| 결과 파일 | MP4 재생 가능 여부, SRT·장면별 JSON·검사 결과의 존재와 경로 검사 | 미구성 |
| 자동 품질 검사 | 영상 길이 목표 ±10%, 해상도, 자막 타이밍을 도구 결과와 비교 | 미구성 |
| 사람의 품질 확인 | 인물·배경 일관성, 음성 동기화, 내용 적절성을 개인이 영상 파일로 확인하고 피드백 기록 | 미구성 |

초기 데이터는 [확정 ADR](decisions/0004-synthetic-data.md)에 따라 합성·공개 예제만 사용한다. 실제 참고 자료, 개인정보, 음성·초상 또는 외부 서비스가 필요한 검사는 해당 결정과 사용 범위를 먼저 확정한다. 지금은 전체 제작·미디어 검사용 명령이 **미구성**이며 성공 여부를 주장하지 않는다.
