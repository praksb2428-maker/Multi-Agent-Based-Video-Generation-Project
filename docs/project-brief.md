## 데이터·키·개인정보

- 선택 기준 이미지는 사용자가 명시 실행한 프롬프트 보강과 예시 이미지 요청에 OpenAI로 전송된다. 인물·개인 자료를 사용한다면 전송 가능 범위와 권리를 먼저 확인해야 한다. 제안서 §3.2는 참고 자료의 출처·사용 범위를 기록하도록 제안한다.
- 키는 `OPENAI_API_KEY` 또는 Git 제외 `.env`에서 서버만 읽는다. 브라우저·작업 JSON·로그·테스트에 넣지 않는다. 원본·예시·MP4는 Git 제외 `workspace/storyboards/`에 남는다. 보존 기간과 삭제 절차는 아직 정하지 않았다.
- 테스트는 합성 이미지와 모의 API 응답을 사용한다. 출력 이미지 단가 참고값은 총 비용이나 상한이 아니다. 실제 과금·품질·사람 수락은 검사 통과로 주장하지 않는다.
