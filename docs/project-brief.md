# 프로젝트 브리프: 숏츠 제작 멀티 에이전트팀

## 근거와 상태 표기

요청된 `proposal.md`는 현재 저장소에 없다. 사용자는 [`Video_Production_Project.md`](../Video_Production_Project.md)를 이 작업의 제안서 원본으로 확정했다. 참고 프로젝트 분석 보고서는 별도 자료이며 이 프로젝트의 확정 요구사항으로 취급하지 않는다. 확정 선택의 기준 기록은 [ADR](decisions/README.md)이다.

- **명시된 사실**: 제안서에 직접 적힌 목표·계획·후보. 미래형 서술은 구현 완료를 뜻하지 않는다.
- **현재 상태**: 저장소 파일을 읽어 확인한 구현·구성.
- **확정 결정**: 제안서에 없는 사항에 대해 사용자가 이번 작업에서 선택한 방향.
- **제안**: 초기 개발 환경을 구성할 때 적용하면 좋을 방침. 승인된 요구사항은 아니다.
- **미정**: 제안서나 현재 파일로 결론 낼 수 없는 선택.

## 현재 저장소 상태와 간극

- **현재 상태 · GUI 로컬 AI 기획 연결**: 기존 입력 양식의 기획 방식에서 실제 로컬 AI를 선택하고 생성 버튼을 누르면 J의 고정 provider로 미승인 기획·대본을 만든다. 기본 템플릿과 두 승인·수정 후 재승인은 유지한다. 모델 서버 실패는 한국어 안내와 새 작업 미생성이며 조회/재시작/승인/명시 수정에서 재호출하지 않는다. 모의 HTTP 영향47개가 통과했고 실제 브라우저·생성 결과는 K 회차 기록에서 별도로 확인한다. 내용의 사실성·의미적 금지 준수와 사용자 채택은 자동으로 판정하지 않는다. [ADR0015](decisions/0015-gui-local-planning.md), [GUI 안내](shorts-production.md)

- **현재 상태 · 실제 로컬 기획 CLI**: 사용자 승인으로 Ollama 0.40.16 portable·qwen3.5:4b-q4_K_M을 프로젝트 workspace에 준비했다. draft-local의 실제 한글 생성은 36.703초에 미승인 JSON을 저장했고 관련 62개 검사가 통과했다. 내용의 사실성과 금지 의도 준수는 통과로 판정하지 않았으며 사용자 채택은 대기다. GUI·AI 영상/TTS는 이번 실제 연결 대상이 아니다. [ADR0014](decisions/0014-local-ollama-planning.md), [검사](testing.md)

- **현재 상태 · TXT 제작 요구**: Python localhost GUI가 기존 기획·연출·견적·별도 두 승인·합성 제작/검사·명시 확인·수정 재승인을 연결한다. 프로젝트 전용 스킬 5개, 8개 설계 책임 매핑, 아키텍처 그림·시연 안내를 제공한다. 로컬 모델은 사용자 선택대로 연결 어댑터와 모의 검사까지만 준비했다. 실제 모델 설치·LLM 팀 호출을 뜻하지 않는다. [요구와 범위](harness.md), [실행·시연](shorts-production.md), [ADR0013](decisions/0013-local-gui-harness.md)

- **현재 상태 · 수정 요청부터 모의 재제작**: 명시적 교체 JSON을 현재 `changes_requested` 원본 검토에 결속하고 별도 수정 초안을 저장한다. 사용자의 기획 재승인 뒤 연출·프롬프트·새 모의 견적을 준비하고, 별도의 새 모의 제작 승인과 명시 CLI 호출에서만 새 결과를 만든다. 원본·각 승인 대기 상태를 보존하고 재개 시 현재 원본과 새 입력을 다시 검사한다. 실제 AI·비용·자동 승인·문제 해결 추론 없이 새 사람 확인을 기다린다. [ADR 0012](decisions/0012-mock-rework.md), [검증](testing.md#수정-요청과-별도-재승인-모의-재제작)

- **현재 상태 · 결과 검사/수정 요청**: 별도 검사보고, 명시적 확인 JSON과 단계별 수정 요청 경로, 저장 기록의 현재 입력·결과 재검증을 구현했다. 기술 실패 수락은 거부하고 원본 결과·품질 보고는 보존한다. 자동 수정·자동 승인·재생성은 없으며, 합성 테스트의 확인 표기는 실제 사용자 채택이 아니다. 80개 회귀와 기존 30초 결과 CLI 재검사가 통과했다. [검사 근거](testing.md#결과-검사보고와-수정-요청)

- **현재 상태 · 로컬 합성 제작/검사**: 사용자 요청에 따라 `produce-mock`가 유효한 모의 승인에서 색상 카드·무음 MP4와 SRT·장면 JSON·품질 보고·manifest를 생성한다. `validate-result-mock`가 현재 입력과 생성 시점 승인의 결속, 실제 probe/전체 디코드/무음·SRT·해시를 재검사한다. 69개 테스트와 실제 30초 CLI 경로가 통과했다. 실제 AI 영상·TTS·지출 허가는 아니며 사람의 최종 채택은 별도다. [검사 근거](testing.md#로컬-합성-제작과-결과-검사)
