# ADR 0011: 로컬 결과 검사와 수정 요청

- 상태: 확정된 사용자 요청에 따른 로컬 구현, 독립 검토는 별도
- 날짜: 2026-10-30
- 결정자: 프로젝트 사용자(후속 기능 진행 요청), 구현 담당(범위 내 계약 설계)

## 배경

사용자는 남아 있는 파일 닫기 경고를 고치고 기획안의 다음 기능을 비용 없이 순서대로 진행하도록 요청했다. 기획안 §3의 결과 검사·사용자 피드백·변경 후 재승인 흐름을 연결한다. [이전 제작 단계](0010-local-mock-media.md)의 원본 결과와 생성 시점 승인 정책을 보존한다.

## 선택지와 결정

자동 수정/재생성 대신 별도의 검사보고와 명시적 JSON 확인 기록을 선택했다. 현재 입력 여섯 개와 결과 manifest·payload, 검사 및 확인 내용을 SHA-256으로 결속하고 재검증 시 실제 기술 검사를 다시 실행한다. 변경·오래된 연결·실패 검사 수락은 거부한다.

기술 실패의 단계 정보와 사용자가 입력한 항목을 고정된 후속 행동 ID로 안내한다. 내용은 기획, 시각은 연출/프롬프트, 타이밍·자막은 제작/편집으로 연결하며 원인 불명은 수동 확인으로 멈춘다. 이 안내는 명령 실행이나 자연어의 AI 해석이 아니다.

## 영향과 경계

새 명령은 `inspect-result-mock`, `review-result-mock`, `check-result-review-mock`다. 원본 결과와 `quality.json`은 덮어쓰지 않는다. 확인자 표기는 자기보고이며 전자서명·실제 시청 인증·최종 사용자 채택·지출 허가가 아니다. 실제 모델·TTS·외부 서비스·자동 반복 작업은 추가하지 않았다. [검증 기록](../testing.md#결과-검사보고와-수정-요청)에 한계와 수리 이력을 남긴다.
