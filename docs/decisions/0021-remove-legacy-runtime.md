# ADR 0021 — 이전 실행 기능 제거

- 상태: 확정
- 날짜: 2026-11-24
- 결정자: 프로젝트 개인 사용자

## 배경

[ADR 0020](0020-gpt-storyboard-local-mp4.md)은 새 8766 스토리보드 작업실을 추가하면서 기존 8765 GUI·CLI를 보존했다. 사용자는 현재 기획안에 필요 없는 파일을 선별·삭제하라고 요청했고, 후속 질문에서 **이전 기능 전체 제거**를 선택했다. 새 경로는 이전 `src/openai_api.py`의 키 읽기 함수만 재사용하고 있었다.

## 선택지

1. 이전 기능 전체 제거: 새 경로만 남아 구조·의존성이 단순해진다. 기존 CLI/모의 GUI와 전용 테스트·예제를 더 이상 실행할 수 없다.
2. 이전 기능 보존, 명백한 중복만 삭제: 과거 시연을 그대로 재현할 수 있지만 현재 작업실과 관계없는 코드·설명·의존성을 계속 관리해야 한다.

## 선택과 이유

사용자가 1을 확정했다. 이전 8765 GUI·CLI·모의 제작 코드, 전용 웹 자산·테스트·예제를 제거한다. 후속 지시에 따라 **처음 구상한 하네스의 스킬·안내 문서들은 원본 그대로 보존**한다. 키 읽기·검증은 `src/storyboard_openai.py`로 옮겨 새 경로를 독립시킨다. 이전 SDK만 쓰던 `openai` 직접 의존성을 `requirements.txt`에서 제거한다. 현재 실행은 `storyboard_web.py`와 `src/storyboard_*`, `web/storyboard.*`만 사용한다.

## 영향

- 기존 명령·8765 화면·모의 제작 시연은 현재 작업본에서 사용할 수 없다. 이전 기능 전용 추적 파일 44개를 제거한다. Git 이력에는 추적 파일의 이전 버전이 남는다.
- `workspace/`, `.venv/`, `.env`와 로컬 사용자 결과는 삭제하지 않는다. 제안서 원본, **초기 하네스의 `harness/skills/`·`docs/harness.md`·`docs/shorts-production.md`·`requirements.md`**, 과거 ADR·보고서·증빙 이미지는 당시 이력으로 보존한다. 과거 기록의 이전 소스 링크는 현재 작업본에 파일이 없을 수 있다.
- README·AGENTS·아키텍처·테스트 계획은 새 작업실 기준으로 갱신한다. 실제 OpenAI 유료 호출은 이 정리 회차에 수행하지 않는다.
