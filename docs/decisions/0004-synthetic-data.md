# ADR 0004: 초기 검증 데이터

- **상태:** 확정
- **배경:** [제안서 §3.2~3.3](../../Video_Production_Project.md#L28)는 선택적 참고 자료의 출처와 사용 가능 범위를 요구하지만 실제 자료는 지정하지 않는다. [초기 질문 4](../open-questions.md#4-개발검증-데이터)
- **선택지:** A. 합성·공개 예제만 사용 / B. 사용권을 확인한 실제 자료 사용
- **선택과 이유:** A. 초기 JSON·승인 검증은 합성 예제로 가능하며 자료 사용권·개인정보 문제를 피할 수 있다.
- **영향:** `examples/`와 `tests/`에는 실제 개인 자료·음성·초상·키를 넣지 않는다. 실제 자료 도입 전 출처, 사용 범위, 저장·삭제 기준을 개인과 결정한다.
- **결정자:** 개인(사용자)
- **날짜:** 2026-10-27
