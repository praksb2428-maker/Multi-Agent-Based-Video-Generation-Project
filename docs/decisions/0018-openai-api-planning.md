# 0018: GPT-6.1 Sol API 기획·대본 생성

- 상태: 사용자 지정 제공자·모델의 연결 구현. 실제 유료 검증은 키 미설정으로 미실행.
- 결정자: 사용자. 날짜: 2026-11-17.
- 근거: “api를 받아와서 사용하는 방식”, “gpt 6.1 sol 모델”, 후속 답변 “아직 없고 어느 로컬파일에 입력해야하는지만 알려줘”.

## 선택과 범위

로컬 Ollama 설치 대신 GUI에 명시 `openai_api` 모드를 추가한다. OpenAI의 `gpt-6.1-sol` 모델과 `https://api.openai.com/v1/responses` endpoint를 서버에 고정한다. 기존 `httpx==0.28.1`로 요청하며 새 의존성은 추가하지 않는다. [공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-6.1-sol)와 [구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)을 기준으로 한다.

이 결정은 [0016](0016-gui-api-mock.md)의 모의 경로를 보존하면서 별도 실제 기획 경로만 추가한다. 기존 템플릿이 기본값이다. OpenAI 응답의 reasoning 항목을 허용하되 창작 결과는 단일 assistant 메시지의 `hook/story/scenes`로 검증한다. 입력 조건·출처·비용·승인은 앱이 소유한다. 미승인 초안의 출처는 `openai_api:gpt-6.1-sol`이다.

## 키·전송·비용

서버 환경의 `OPENAI_API_KEY` 또는 Git 제외 저장소 루트 `.env`의 해당 키 한 개만 읽는다. 브라우저는 키·모델·외부 주소를 전달할 수 없다. 키를 HTML·작업 JSON·로그·예제에 기록하지 않는다. 고정 HTTPS 주소, 인증서 검증, 프록시 환경 미사용, redirect 미추적을 유지한다. 키 발급·결제·구매·충전·기존 자격 증명 탐색은 수행하지 않는다.

명시 모드 선택과 생성 버튼 실행 시 입력 조건·선택한 모의 참고 자료를 OpenAI에 보낸다. UI는 전송과 API 과금을 해당 버튼 근처에 알린다. 입력 최대 16KB, 출력 최대 4096토큰, 낮은 reasoning effort, 연결 대기 10초·각 읽기의 무응답 대기 120초, 응답 최대 256KB, `store=false`다. 응답 조각마다 120초 경과 여부를 검사하며 4096바이트 버퍼가 차기를 기다리지 않는다. 네트워크 읽기 중에는 경과 검사를 실행하지 못하므로 전체 실행의 절대 120초 상한은 제공하지 않는다. 모의 제작 예산은 실제 API 요금 상한이 아니다. 정확한 청구는 제공자의 사용 내역을 기준으로 하며 오류에도 청구 가능성이 있다. 자동 재시도·fallback은 없다.

## 승인과 검증

기획은 별도 사용자 승인 전까지 미승인이다. 영상·TTS는 계속 모의 제작이며 기존 `real_execution_allowed: false`는 이 제작 범위를 가리킨다. 조회·재시작·승인·명시 patch 수정은 모델을 호출하지 않는다. 실패한 응답은 새 작업으로 저장하지 않고 기존 파일을 보존한다.

자동 검사는 가짜 키와 메모리 HTTP 응답을 사용한다. 실제 유료 외부 검증은 수행하지 않으며, 개인 정책의 `verify_external_paid_isolated` 계약 없이 유료 시험을 실행하지 않는다. 사용자 키가 없어 실제 계정의 모델 접근·청구·생성 내용 품질은 미검증이다. 키 입력 후 사용자의 명시 생성이 필요하다. 이전의 로컬 기획·모의 제작 승인 범위를 실제 영상 제작 권한으로 확대하지 않는다.
