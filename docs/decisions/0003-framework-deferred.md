# ADR 0003: 에이전트 프레임워크 선택 보류

- **상태:** 확정
- **배경:** [제안서 §4.2](../../Video_Production_Project.md#L42)는 CrewAI를 후보로 두고 JSON 전달·승인 후 재개·도구 호출을 시험한 뒤 확정하도록 한다. [초기 질문 3](../open-questions.md#3-에이전트-실행-프레임워크)
- **선택지:** A. JSON 계약·승인 상태를 먼저 유지하고 프레임워크 보류 / B. CrewAI를 초기 하네스에 포함
- **선택과 이유:** A. 현재 오프라인 기획 단계를 그대로 검증하고 성급한 결합을 피한다.
- **영향:** 이 ADR은 CrewAI 사용 여부 자체를 확정하지 않는다. 프레임워크 채택 전에는 별도 비교·검증과 개인 확인이 필요하다.
- **결정자:** 개인(사용자)
- **날짜:** 2026-10-27
