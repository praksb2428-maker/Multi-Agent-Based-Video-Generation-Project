# ADR 0009: 가상 단위 견적과 모의 제작 승인

- **상태:** 사용자 요청 범위 구현·검증, 독립 검토 대기
- **배경:** 사용자가 “우선 비용이 발생하지 않는 견적·제작 승인 모의 기능부터 이어서 만들어줘”라고 요청했다. 실제 제공자·요금·결제·키·서비스 호출 결정은 하지 않았다.
- **선택지:** A. 합성 가격표와 로컬 확인 기록 / B. 실제 제공자 요금·호출·결제 연결
- **선택과 이유:** A. `fictional_test_only` 출처, `mock_credit` 가상 정수 단위로만 검사한다. 예제 단가는 임의 테스트 값이며 `max_budget` 숫자를 가상 한도로 비교하는 것은 실제 통화 해석이나 과금 한도 설정이 아니다.
- **산식:** 각 장면의 초 길이를 올림해 영상 단가를 곱하고, 대본 Unicode 문자 수의 100자 블록을 올림해 내레이션 단가를 곱한다. 편집 고정 항목은 프로젝트당 한 번 더한다. 올림은 Decimal, 합계는 정수로 계산하며 단가는 0~10억 정수, 합계는 signed-64 범위다. 예산 초과 견적 저장은 허용하고 모의 승인은 거부한다.
- **결속:** 현재 유효 승인 기획에서 연출·프롬프트를 재도출해 비교한다. 견적에는 기획·연출·프롬프트·가격표의 전체 내용 SHA-256을 넣고 승인 전 내역·금액·한도를 재계산한다. canonical 직렬화는 UTF-8, 키 정렬, `ensure_ascii=False`, `allow_nan=False`, 구분자 `,`·`:`다.
- **모의 승인:** 별도 버전1 wrapper가 `mock_only` 범위, `mock_approved` 상태, `real_execution_allowed: false`, 정책 `mock-production-v1`, 정확한 견적 해시·사유·호출자 표기·UTC 승인 시각·만료를 기록한다. 내용 해시는 이 필드 전체에 결속한다. 1시간은 고정 테스트용 유효기간이며 실제 서비스 승인 정책이 아니다. 호출자 표기는 인증이 아니고 해시는 서명이나 지출 권한이 아니다.
- **제약:** 기획·연출·프롬프트·단가·견적 변경, 만료·미래 시각·변조는 재견적/재승인을 요구한다. 원 기획/프롬프트는 수정하지 않으며 원 `production_approval`는 null이다. 실행기·API·계정·키·실제 금액·미디어·새 의존성은 도입하지 않는다. [ADR 0005](0005-offline-services.md)의 외부 호출 전 별도 결정 경계는 유지한다.
- **결정 근거:** 개인(사용자)의 모의 기능 개발 요청 범위. 새로운 비용·결제·외부 실행 승인 아님.
- **날짜:** 2026-10-30
