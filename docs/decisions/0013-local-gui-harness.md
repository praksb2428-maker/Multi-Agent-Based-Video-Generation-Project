# ADR 0013: TXT 제작 요구와 로컬 GUI·모델 연결 모의 준비

- **상태:** 확정된 범위의 구현. 브라우저·독립 검토 결과는 작업 기록에서 별도로 확인한다.
- **배경:** 사용자가 강의 TXT를 실제 제작 요구로 채택하고 기존 프로젝트의 부족한 부분을 순서대로 만들도록 요청했다. 기획·제작 승인 유지와 비용 없는 범위가 조건이다.
- **선택지:** 로컬 모델 연결/모의 검사부터 준비, 기존 모델 사용, PC 사양 확인 후 선택, 모델 후속 보류, 모의 실행만 유지.
- **선택과 이유:** 사용자는 “연결 코드와 모의 테스트부터 만들기 — 설치 없이 준비하고 실제 모델 실행은 환경이 정해진 뒤 검증”을 선택했다. 기존 Python·JSON·함수 계약을 유지하며 GUI는 표준 라이브러리 loopback 서비스와 로컬 HTML/CSS/JS로 연결한다. 새 프레임워크·의존성·DB는 추가하지 않는다.
- **영향:** 프로젝트 한정 스킬·역할/아키텍처·GUI·시연 안내를 만든다. GUI의 두 승인은 각 명시 사용자 동작에서만 생성한다. 수정 후 새 견적·두 재승인이 필요하다. 모의 모델 어댑터는 httpx.MockTransport만 받고 실제 연결 옵션을 제공하지 않는다.
- **보존:** 제안서 원본·기존 CLI·승인/결과는 보존한다. 역할은 8개 설계 책임으로 표현하고 실제 LLM 팀 실행을 주장하지 않는다. 참고 자료 없음은 정상 경로다.
- **보류/제외:** 실제 로컬 모델·런타임 선정/설치/성능, 실제 영상/TTS API·과금·키·게시·RAG·전역 스킬 설치는 제외한다. 프로세스·임시물은 검증 후 소유권을 확인해 정리한다.
- **결정자:** 개인(사용자)의 원문 범위와 로컬 모델 질문의 명시 답변. loopback 경로·고정 action·화면 배치는 기존 Python 범위의 구현 선택이다.
