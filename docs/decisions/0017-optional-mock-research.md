# ADR 0017: 기획 전 선택형 모의 자료 조사

- **상태:** 사용자의 모의 구현 범위는 확정. 구현 후보의 검사·독립 검토·개인 채택은 이번 작업 기록에서 구분한다. 실제 인터넷 검색은 미연결이다.
- **배경:** 사용자가 강의의 인터넷 검색 내용을 참고해 기존 구조와 승인 단계를 유지하면서 기획·대본 전 선택적 자료 검색과 출처 정리를 요청했고 비용 없는 모의 테스트부터 진행하도록 했다.
- **선택과 이유:** 새 프레임워크·검색 서비스·키·패키지를 도입하지 않고 고정된 합성 자료 2개로 검색→출처 정리→기획 문맥 전달을 연결한다. 기본 선택은 OFF이며 기존 API payload·기획·승인 해시는 자료가 없으면 그대로다.
- **입출력:** 명시 검색은 전체 brief에 결속된 schema1 packet과 서버 발급 ID를 저장한다. 제목·모의 주소·요약·출처 ID·미검증 경고를 미리보기와 저장된 기획에 표시한다. 생성은 임의 packet/URL 대신 발급 ID만 받고 현재 조건·고정 자료와 다시 대조한다. URL은 .invalid의 모의 텍스트이며 클릭·수집하지 않는다.
- **문맥·승인:** 템플릿·합성 응답은 첫 자료의 요약을 명시적인 모의 참고 문구로 사용한다. SDK/로컬 요청에도 검증되지 않은 참고 데이터라는 문맥을 전달한다. 실제 모델 품질은 이번에 검증하지 않는다. 자료 전체를 선택적 plan.research로 저장하고 기존 기획 승인 해시에 포함한다. 모델이 출처·승인·비용·brief를 바꿀 수 없다. 별도 기획/제작 승인과 명시 제작은 그대로다.
- **변경·복구:** 모든 입력 조건 변경 또는 OFF/ON 재선택 시 재검색해야 한다. 빈 결과는 생성하지 않고 재검색 또는 OFF를 안내한다. 조회·재시작·승인·편집·제작은 검색을 다시 하지 않는다. 명시적 대본 수정은 같은 자료를 보존하며 새 두 승인이 필요하다. 자료 자체를 바꾸려면 새 기획으로 시작한다.
- **원 기획안과 구분:** 원본의 RAG/벡터 DB 제외 문구는 당시 범위로 보존한다. 이번 요청은 검색 자료를 기획 문맥에 넣는 제한된 검색 증강의 모의 확장이다. 임베딩·벡터 DB 기반 문서 RAG나 실제 외부 검색을 승인한 것은 아니다. 실제 서비스·비용·키·전송 범위는 후속 결정 사항이다.
- **영향·검사:** 선택적 메타데이터를 검증하고 내용 해시에 결속한다. legacy 기획/승인 golden·모의 검색/SDK/로컬 payload·stale/변조/주입·두 승인/수정·기존 저장 작업·전체 회귀와 부모 CUA를 확인한다. 해시는 변경 감지이며 인증·서명이 아니다. 기존 native200% 확대 HOLD는 유지한다.
