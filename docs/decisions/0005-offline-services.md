# ADR 0005: 외부 API와 유료 검증 시점

- **상태:** 확정
- **배경:** [제안서 §4.1](../../Video_Production_Project.md#L38)는 OpenAI 사용을 계획하지만 영상 제공자·모델·구체적 예산은 확정하지 않았다. [초기 질문 5](../open-questions.md#5-외부-api와-유료-검증-시점)
- **선택지:** A. 초기 하네스는 오프라인으로 검증하고 유료 호출은 별도 결정 / B. 승인된 예산 내 실제 API 시험까지 준비
- **선택과 이유:** A. 비용 산정·제작 승인 기능이 없는 현재 단계에서는 키·외부 호출 없이 파일 계약을 검증한다.
- **영향:** API 키와 외부 서비스 연결은 현재 하네스에 필요 없다. 실제 호출 전 제공자·모델, 호출·총액 한도, 전송 자료, 키 취급과 승인 지점을 별도로 확정한다.
- **결정자:** 개인(사용자)
- **날짜:** 2026-10-27
