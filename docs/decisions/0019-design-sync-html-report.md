# ADR 0019: 구현·설계 동기화와 HTML 구조 보고

- **상태:** 확정
- **배경:** 사용자 요청으로 이후 구현마다 설계 문서를 반영하고, 만든 파일과 구조를 아키텍처 방식의 HTML로 설명해야 한다. 기존 `project-check`는 검사 실행 담당이며 테스트 설계·작성과 역할이 다르다.
- **선택지:** A. 규칙 문장만 추가 / B. 프로젝트 전용 스킬과 로컬 Git 변경 가드, HTML 보고를 연결 / C. 전역 스킬·외부 CI로 배포
- **선택과 이유:** B. 이 저장소의 실제 경로와 승인 흐름에 맞춘다. 전역 설치·외부 서비스 변경 없이 동반 문서 갱신 누락을 검출하고 사람이 의미를 검토한다.
- **영향:** 구현 변경 후보에는 `docs/architecture.md` 또는 `AGENTS.md` 변경을 포함한다. 구조가 바뀌면 `docs/architecture.html`에 계층과 생성/수정 파일을 반영한다. `project-test-design`은 테스트 작성, `project-check`는 독립 실행·기록, `project-architecture-report`는 구조 설명을 담당한다. 가드는 문서 변경의 존재만 검사하며 설계 정확성은 검토자가 판단한다.
- **결정자:** 개인(사용자)
- **날짜:** 2026-11-24
