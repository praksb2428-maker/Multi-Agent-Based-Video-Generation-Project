# 의사결정 기록(ADR)

이 디렉터리는 **개인이 확정한 프로젝트 결정**의 기준 정보다. [기존 질문과 답변](../open-questions.md)은 선택 당시의 문맥을 보존하고, 각 ADR은 현재 유효한 선택과 영향을 기록한다. 새 결정은 `000N-주제.md`로 추가하고 기존 결정을 바꾸면 새 ADR에서 이전 기록을 연결한다.

## 개인 확인 기준

작업 전에 선택지, 장단점, 추천 이유, 영향과 예상 비용·데이터 범위를 제시하고 개인에게 확인한다.

- 언어·프레임워크·의존성 관리 같은 기술 스택 또는 실행 환경 변경
- 실제/개인 자료의 사용, 저장 위치·보존·삭제 방식, 키 취급 방식 변경
- 유료 호출·재생성·결제 또는 비용 상한 변경
- 외부 서비스 연결, 데이터 외부 전송, 공개·배포
- 목표 산출물, 승인 지점, 품질 기준 등 프로젝트 범위 변경

결정에 영향을 주지 않는 오탈자, 링크 보정, 파일 정리, 범위 내 테스트 수정은 매번 개인 승인을 요구하지 않는다. 확인이 필요한 변경은 답변 전까지 실행하지 않는다. 특히 기획 승인 기록은 유료 제작 승인으로 간주하지 않는다.

## 기록 형식

각 ADR에는 **상태(제안/확정/보류), 배경, 선택지, 선택과 이유, 영향, 결정자, 날짜**를 적는다. 근거 문서와 이전 ADR을 연결하고, 아직 결정되지 않은 사항을 확정처럼 쓰지 않는다.
