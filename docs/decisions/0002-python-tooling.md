# ADR 0002: Python 개발 도구

- **상태:** 확정
- **배경:** [제안서 §4.3](../../Video_Production_Project.md#L47)는 Python 3.12 가상환경·VS Code·Git/GitHub를 정했지만 의존성 관리 도구는 미정이었다. [초기 질문 2](../open-questions.md#2-python-의존성-관리-도구)
- **선택지:** A. `venv` + `pip` + 명시적 의존성 파일 / B. `uv` + 잠금 파일
- **선택과 이유:** A. 기존 표준 라이브러리 코드에 맞고 새 도구 없이 시작할 수 있다.
- **영향:** `requirements.txt`를 의존성 기준 파일로 둔다. 현재 설치할 외부 패키지는 없다. 추가 시 버전을 명시하고 필요성을 검토한다.
- **결정자:** 개인(사용자)
- **날짜:** 2026-10-27
