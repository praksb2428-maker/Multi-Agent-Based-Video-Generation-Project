# ADR 0001: 제안서 원본

- **상태:** 확정
- **배경:** 요청에는 `proposal.md`가 있었으나 저장소에는 없고, 기존 README·`requirements.md`는 `Video_Production_Project.md`를 원 기획안으로 지목한다. [초기 질문 1](../open-questions.md#1-제안서-원본)
- **선택지:** A. 현재 `Video_Production_Project.md`를 원본으로 확정 / B. 별도의 `proposal.md`를 제공받아 재검토
- **선택과 이유:** A. 현재 저장소와 일치하는 제안서 원본을 사용한다.
- **영향:** [프로젝트 브리프](../project-brief.md)와 후속 문서는 이 파일의 절·문장을 근거로 삼는다. 원본이 바뀌면 영향받는 문서를 다시 검토한다.
- **결정자:** 개인(사용자)
- **날짜:** 2026-10-27
