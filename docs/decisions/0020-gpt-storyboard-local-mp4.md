# ADR 0020 — GPT 지휘와 로컬 이미지 영상 합성

- 상태: 확정
- 날짜: 2026-11-24
- 결정자: 프로젝트 개인 사용자

## 배경

사용자는 기존 복잡한 UI를 줄이고 프롬프트·선택 이미지 → 10초 구간 프롬프트와 예시 이미지 → 사람 검토 → 최종 영상 생성·다운로드를 요청했다. 기존 OpenAI 키를 사용하고 예시 및 최종 생성 전에 비용 안내를 원했다. 이후 Runway 사용을 거부하고 “gpt api를 지휘 역할로 사용을 해서 영상 mp4를 제작하는 방식”을 명시했다. [OpenAI 폐기 안내](https://developers.openai.com/api/docs/deprecations)에 따르면 Sora 2/Videos API는 2026-09-24 종료되어 기존 OpenAI 영상 API로 MP4를 생성할 수 없다.

## 선택지

1. 별도 영상 모델 API: 피사체의 연속 동작 생성이 가능하지만 별도 공급자·키·비용이 필요하다. 사용자가 현재 거부했다.
2. OpenAI GPT·이미지 API + 로컬 FFmpeg: 기존 키로 장면을 설계·이미지를 만들고, 로컬에서 확대·이동·전환한 MP4를 만든다. 연속 동작 생성은 제공하지 않는다.
3. 영상 생성 보류: MP4 요구를 충족하지 못한다.

## 선택과 이유

2를 선택한다. `gpt-6.1-sol`은 사용자 프롬프트와 첨부 이미지를 해석하고 정확히 10초 단위 구간의 이미지 프롬프트·카메라 이동을 구조화해 반환한다. `gpt-image-2`는 각 구간의 대표 이미지 한 장을 생성한다. 사용자가 프롬프트와 이미지를 검토해 최종 승인하면 로컬 FFmpeg가 이를 10초 H.264 조각으로 만들고 10·20·30초 무음 MP4로 이어 붙인다. 앱은 GPT의 제안을 검증한 뒤 각 단계의 명시적 사용자 동작에서만 실행한다. 이미지를 움직이는 합성 결과임을 UI와 안내에 표시한다.

## 영향과 경계

- 예시 이미지 생성은 각 버튼에서 예상 출력 단가를 안내한다. 입력 토큰·프롬프트 보강 요금은 별도이며 화면의 참고값은 총액이나 비용 상한이 아니다. 최종 렌더는 추가 영상 API 호출 없이 로컬 FFmpeg로 실행한다.
- 프롬프트와 첨부 이미지는 명시 요청 시 OpenAI로 전송된다. 키는 서버 환경 또는 Git 제외 `.env`에서만 읽고 브라우저·저장 작업에는 넣지 않는다. 원본·예시·영상은 Git 제외 `workspace/storyboards/`에 보관한다.
- 예시를 모두 확인한 작업에서만 최종 렌더가 가능하다. 거절·오류는 중단하며 자동 재시도·공급자 전환이 없다. 입력·예시·승인·영상 파일 해시로 우발적 변경을 감지한다. 해시는 사용자 인증이 아니다.
- 기존 CLI와 8765 GUI는 보존한다. 새 간결한 화면은 `storyboard_web.py`의 8766에서 제공한다.
- 실제 OpenAI 유료 호출과 결과 품질은 키 없이 검증하지 않았다. 합성 응답·로컬 FFmpeg 결과만 검사했다.
