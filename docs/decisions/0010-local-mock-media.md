# ADR 0010: 로컬 합성 모의 제작과 결과 검사

- **상태:** 사용자 요청 범위 구현·검증, 독립 검토 대기
- **배경:** 사용자가 “이제 비용이 발생하지 않는 모의 제작과 결과 검증 기능도 기획안에 맞춰서 순서대로 만들어줘”라고 요청했다.
- **선택지:** A. 기존 로컬 FFmpeg로 색상·무음 시험 매체 생성 / B. 실제 AI 영상·음성 서비스와 비용 연결
- **선택과 이유:** A. 이미 설치된 FFmpeg/FFprobe를 사용하고 새 설치·키·API·유료 호출은 하지 않는다. `real_execution_allowed: false`를 유료 제작 권한으로 바꾸지 않는다. 이번 요청이 허용한 로컬 합성 시험만 `mock_only` 승인으로 진행한다. [ADR 0009](0009-mock-quote-approval.md)의 기존 경계와 기록은 유지한다.
- **프로필:** 24fps, 비율에 맞는 짝수 96~640px, 최대60장면. 누적 초 길이를 nearest frame/half-up으로 양자화하고 SRT는 nearest ms/half-up이다. 표시 가능한 한 프레임 이상 장면과 최종 목표 ±10%를 요구한다. SRT CR·빈 문단·가장자리 빈 줄은 원문을 변환하지 않고 거부한다.
- **산출·보존:** workspace 아래 새 결과 폴더에 고정 MP4/SRT/scenes/quality/manifest를 생성한다. 원본·기존 출력은 덮어쓰지 않는다. 내부 `.work/`와 실패 시 `failure.json`·부분 결과를 보존하며 자동 재시도·삭제는 하지 않는다. 사용자 글은 SRT 데이터로만 사용하고 외부 URL이나 필터/셸 코드로 해석하지 않는다.
- **검사:** 버전1 manifest는 모든 현재 입력과 파일 SHA-256/크기·프로필·도구 버전·생성 시작 UTC 시각을 기록한다. canonical SHA는 기존과 같은 UTF-8, 키 정렬, `ensure_ascii=False`, `allow_nan=False`, 구분자 `,`·`:`다. 품질 보고는 핵심 payload 해시에 결속하고 manifest가 보고까지 해시하여 순환하지 않는다. 검사 시 저장된 성공 플래그 대신 실제 probe·전체 디코드·PCM 무음·SRT/장면·현재 입력/승인 결속을 재확인한다.
- **시간·권한 의미:** 제작은 현재 승인 유효성부터 검사한다. 사후 기술 QA는 생성 시작 시점의 승인 유효성을 확인하므로 이후 만료만으로 기존 파일을 실패로 바꾸지 않는다. 입력이 달라지면 거부한다. 해시는 변경 감지이며 인증이나 서명이 아니다. 색상 카드의 기술 pass는 AI 내용/영상 모델 품질·음성 동기화·사용자 최종 채택이 아니다.
- **실행 경계:** 명시적 로컬 argv, `shell=False`, timeout, `-nostdin`·`-n`, 고정 합성 입력·내부 목록과 file/pipe 프로토콜을 사용한다. 결과 경로/파일의 상위 이동·링크·예상 밖 이름을 거부한다. OS 방화벽 격리·실제 생성 서비스는 구성하지 않는다.
- **결정 근거:** 개인(사용자)의 이번 로컬 모의 제작·검사 개발 요청 범위이며 새로운 서비스·비용 승인이나 정책 전역 변경이 아니다.
- **날짜:** 2026-10-30
